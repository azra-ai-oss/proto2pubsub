# proto2pubsub

[![CI](https://github.com/protocgen/proto2pubsub/actions/workflows/ci.yml/badge.svg)](https://github.com/protocgen/proto2pubsub/actions/workflows/ci.yml)

A `protoc`/`buf` plugin that flattens `.proto` files into self-contained schemas
compatible with [GCP Pub/Sub's schema registry](https://cloud.google.com/pubsub/docs/schemas).

## Why?

GCP Pub/Sub schemas have strict requirements:
- **No `import` statements** — the `.proto` text is parsed standalone
- **Single top-level message** — one root message per schema
- **No custom options/annotations** — `field_behavior`, `buf.validate`, etc. are rejected
- **≤ 300 KB** schema definition size

If your `.proto` files use imports, annotations, or well-known types like
`google.protobuf.Timestamp`, they can't be used directly as Pub/Sub schemas.

**proto2pubsub** solves this by generating a clean, self-contained `.proto` file with:
1. All `import` statements removed
2. All custom options/annotations stripped
3. All referenced types (including cross-file and well-known types) inlined as nested definitions
4. A single root message

## Installation

### From the Go module registry

```bash
go install github.com/protocgen/proto2pubsub@latest
```

Or download a pre-built binary from [Releases](https://github.com/protocgen/proto2pubsub/releases).

### Build from source (local development)

Clone the repository and install the binary directly from your working tree.
This is useful when iterating on the plugin locally or when you need changes
that haven't been published yet.

```bash
git clone https://github.com/protocgen/proto2pubsub.git
cd proto2pubsub

# Build the binary in the current directory
go build -o protoc-gen-proto2pubsub .

# Install it to $(go env GOPATH)/bin so it's available globally
go install .
```

Verify the install:

```bash
which protoc-gen-proto2pubsub
# e.g. /Users/<you>/.local/bin/protoc-gen-proto2pubsub
```

> **Note:** Make sure `$(go env GOPATH)/bin` (commonly `~/.local/bin` or `~/go/bin`)
> is on your `PATH`. Add one of the following to your shell profile if needed:
> ```bash
> export PATH="$HOME/.local/bin:$PATH"   # or
> export PATH="$HOME/go/bin:$PATH"
> ```

## Usage

### With buf (recommended)

```yaml
# buf.gen.yaml
version: v2
plugins:
  - local: protoc-gen-proto2pubsub
    out: pubsub_schemas
    opt:
      - root_message=Report
```

```bash
buf generate
```

### With protoc

```bash
protoc \
  --proto2pubsub_out=pubsub_schemas \
  --proto2pubsub_opt=root_message=Report \
  your_service.proto
```

### Register with Pub/Sub

```bash
gcloud pubsub schemas create my-schema \
  --type=PROTOCOL_BUFFER \
  --definition-file=pubsub_schemas/report_pubsub.proto
```

## Options

| Option | Default | Description |
|:---|:---|:---|
| `root_message` | auto-detect | Root message name. Required when file has multiple top-level messages. Auto-detected when there's exactly one. |
| `output_file` | `<input>_pubsub.proto` | Override the output filename. |

## Example

Given this input:

```protobuf
syntax = "proto3";
package reporting.v1;

import "google/protobuf/timestamp.proto";
import "buf/validate/validate.proto";

message Report {
  string id = 1 [(buf.validate.field).required = true];
  google.protobuf.Timestamp created_at = 2;
  repeated Finding findings = 3;
}

message Finding {
  string description = 1;
}
```

proto2pubsub generates:

```protobuf
// Generated by proto2pubsub. DO NOT EDIT.
syntax = "proto3";

message Report {
  string id = 1;
  Timestamp created_at = 2;
  repeated Finding findings = 3;

  message Finding {
    string description = 1;
  }

  // Inlined from google.protobuf
  message Timestamp {
    int64 seconds = 1;
    int32 nanos = 2;
  }
}
```

## Development

This project uses [Nix flakes](https://nixos.wiki/wiki/Flakes) for reproducible dev environments:

```bash
# Enter dev shell (or use direnv)
nix develop

# Build
go build -o protoc-gen-proto2pubsub .

# Test
go test ./... -v

# Generate golden files
cd testdata/proto && PATH="$(git rev-parse --show-toplevel):$PATH" buf generate
```
